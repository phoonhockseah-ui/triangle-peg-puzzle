Triangle Peg Puzzle - installable app (PWA)

1. Upload every file in this folder (not the folder itself) to the ROOT of a GitHub repository,
   then Settings > Pages > Deploy from a branch > main > /(root).
2. Laptop (Chrome/Edge, not Incognito): open the site, click the install icon in the address bar.
3. Android (Chrome): open the site, menu > Install app.
